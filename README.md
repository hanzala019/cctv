# cctv
CCTV UX Enhancement. There's a Creating Zone option, motion detection, objection detection, customized alert systyem, recording, key timestamp records, short clips for quick event viewing.

Whats Coming next ?
Tracking, Customized models, Position Prediction and Ai Assistant for efficient querying. Hopefully we can implement this when we are not broke and manage a gpu :)

## Step:1
Clone the repo

## Step:2
run `pip install -r requirements.txt`

## Step:3
run main.py file.
